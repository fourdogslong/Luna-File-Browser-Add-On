# Release notes

## File Browser 1.0.69

This release polishes the appearance of the browser and its public-facing presentation.

- Tuned selected file and folder highlights for the Default and Light panel backgrounds.
- Reworked the Filters and Sort tabs to better fit those backgrounds.
- Matched both search fields and the Preview panel to the selected background theme.
- Added a favorite toggle to the preview area beside the file color swatches.
- Added a feature-focused README and optimized screenshots covering search, filters, preview, Similar Sounds, settings, and the compact Add On layout.
