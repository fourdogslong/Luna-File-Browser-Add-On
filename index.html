File Browser Help
Browse and preview

Choose a folder in Places. Search names, refine with Filters, and change the order with Sort.

Select a sound to preview it. Use the buttons below the preview to add it to the selected track or create a new track.

Click the metronome icon to sync audio preview to the session tempo. If LUNA is already playing, Preview or Auto-Play queues the sound for the next bar’s beat 1. Stopping LUNA stops the preview.

Similar Sounds

Select an audio or MIDI file and choose Find similar. Audio matches are ranked by sound features. MIDI matches are ranked by note, pitch, and rhythm patterns. The original file appears first.

By default, it searches your available sound library. Turn on Find similar only in selected folder, including subfolders in Settings to limit the search.

While analysis is running, click another folder in Places to cancel the current scan and analyze that folder instead. Click the × beside Similar sounds to cancel and return to regular results.

Favorites and colors

Use the star and color controls to mark sounds for later. These are stored per session and may not carry over to another LUNA session.

Search tips

kick OR snare finds names containing either term.

kick -loop finds kicks while excluding names containing “loop”.

Combine them as kick OR snare -loop. Search is case-insensitive; put a phrase in quotes to match it together.
